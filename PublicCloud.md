# Public Cloud

Bei der Public Cloud stellt ein grosser Anbieter seine Rechenzentren allen Kunden zur Verfügung. Mehrere Firmen laufen auf der gleichen Hardware, sind aber logisch voneinander getrennt. Man nennt das Mandantenfähigkeit.

Ressourcen kann man in wenigen Minuten buchen und wieder abbestellen. Bezahlt wird nur, was man auch braucht.

## Beispiele

- Microsoft Azure
- Amazon Web Services
- Google Cloud Platform

## Vorteile

- Keine Investition in eigene Hardware
- Fast unbegrenzt skalierbar
- Abrechnung nach Verbrauch

## Nachteile

- Die Daten liegen bei einem fremden Anbieter, oft im Ausland
- Abhängigkeit vom Anbieter und von der Internetverbindung
