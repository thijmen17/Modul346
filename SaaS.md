# SaaS

Software as a Service.

Bei SaaS benutze ich eine fertige Software über den Browser oder eine App. Installation, Updates, Server und Backup macht alles der Anbieter. Ich melde mich mit meinem Konto an und kann arbeiten. Bezahlt wird meistens pro Benutzer und Monat.

Vergleichbar mit einem Hotelzimmer. Alles ist bereit, ich muss nichts selber machen.

## Wer macht was

| Ebene | Anbieter | Ich |
|---|---|---|
| Rechenzentrum, Hardware | x | |
| Betriebssystem | x | |
| Anwendung | x | |
| Meine Daten und Benutzer | | x |

## Beispiele

- Microsoft 365
- Gmail
- Dropbox
- Salesforce

## Vorteile

- Sofort einsatzbereit
- Keine Wartung
- Von überall erreichbar

## Nachteile

- Kaum anpassbar
- Meine Daten liegen beim Anbieter, das muss man beim Datenschutz beachten
- Ohne Internet geht nichts
