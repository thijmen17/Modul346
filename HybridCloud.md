# Hybrid Cloud

Die Hybrid Cloud ist eine Mischung. Eine eigene Umgebung wie On-Premise oder eine Private Cloud wird mit einer Public Cloud verbunden, meistens über ein VPN oder eine Direktleitung. Beide Teile werden zusammen verwaltet.

Heikle Daten bleiben so im Haus, während weniger kritische Dienste oder kurzfristige Lastspitzen in die Public Cloud ausgelagert werden.

## Beispiel

Eine Firma hat ihre Kundendatenbank im eigenen Serverraum, benutzt aber Microsoft 365 für die Mails. Wenn im Dezember mehr Rechenleistung gebraucht wird, holt sie sich diese zusätzlich bei Azure.

## Vorteile

- Man kann die Vorteile beider Varianten nutzen
- Der Umstieg in die Cloud ist schrittweise möglich

## Nachteile

- Aufwendiger zu verwalten, weil man zwei Umgebungen hat
- Die Verbindung zwischen den beiden Teilen muss gut abgesichert sein
