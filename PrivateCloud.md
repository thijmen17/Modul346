# Private Cloud

Eine Private Cloud benutzt die gleiche Technik wie die Public Cloud, also Virtualisierung und Self Service, steht aber nur einer einzigen Firma zur Verfügung. Sie kann im eigenen Rechenzentrum laufen oder bei einem Dienstleister, der dafür eigene Hardware bereitstellt.

Der Unterschied zu On-Premise ist der Self Service. Ein Mitarbeiter kann sich über ein Portal selber eine VM erstellen, statt beim IT-Support ein Ticket aufzumachen.

## Beispiele für die Technik

- VMware vSphere
- OpenStack
- Proxmox VE für kleinere Umgebungen

## Vorteile

- Hohe Kontrolle über die Daten
- Trotzdem flexibel und schnell
- Gut, wenn Vorschriften eine eigene Umgebung verlangen

## Nachteile

- Teuer im Aufbau
- Die Skalierung ist durch die eigene Hardware begrenzt
